## GMP Checklists

This folder contains copies of the main GMP checklists along with the Python script required to re-generate an HTML version of the detailed GMP training checklist and all raw materials necessary fo all checklist.

- 01 - UNL Food Industry Survey
- 02 - GMP Pre-Assessment Checklist
- 03 - GMP Assessment Checklist (On-Site)
- 04 - Detailed GMP Training Checklist
- 05 - GMP Post-Assessment Feedback Form

For #4 we have the raw/input "Detailed GMP Training Checklist.txt" that may be edited with any text editor to add/remove questions, and even sections, or references and training materials. ALong with the "db-checklist-create.py" Python script to convert the TXT version of the checklist into an interactive HTML application (a copy of which is shown as a proof of concept example).
