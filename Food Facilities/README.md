## FDA Food Facilities in Nebraska

This folder has the FDA Dashboard list of food facilties distilled to render prospective small and medium size manufacturers in Nebraska.

- Old List (an old effort to distill the FDA Dashboard that may not be up to date)
- New List (this project effort to distill the FDA Dashboard list of inspections into a facility list)
- FDA Food NE.fmp12 (A FileMaker database with the same new list distillation effort)
- FDA Food Cosmetics NE.xlsx (Raw list of NE facilities before distillation)
- FDA Food Cosmetics US.xlsx (Raw list of all US facilities before distillation)
